Dati jūsu ierīcē

MetriPin palīdz pievienot mērījumu līnijas un attālumus fotogrāfijām. Lietotne ierīcē apstrādā jūsu izvēlētos vai uzņemtos foto, projektu un foto nosaukumus, izveides datumus, tehniskos ierakstu identifikatorus, līniju novietojumu un attālumus. Arī ātrie mērījumi tiek saglabāti ierīcē. MetriPin konts nav vajadzīgs.

Projekti un foto glabājas lietotnes failos jūsu ierīcē. MetriPin nav sava mākoņa sinhronizācijas pakalpojuma vai funkcijas, kas automātiski augšupielādē projektus izstrādātāja serverī. Izstrādātājs nesaņem piekļuvi jūsu projektiem tikai tāpēc, ka lietojat lietotni.

Foto var ietvert personas, privātas telpas un citus personiskus datus. Importētā attēlā var saglabāties tā metadati, piemēram, uzņemšanas laiks vai vieta. MetriPin metadatu pilnīgu izņemšanu neapsola.

Kamera, foto izvēle un Bluetooth

Kameru izmanto pēc jūsu darbības foto uzņemšanai. Foto izvēlei izmanto iOS izvēlni, kurā jūs norādāt pieejamos attēlus. Bluetooth izmanto mērītāja atrašanai, savienošanai un attālumu saņemšanai. Atmiņā izmanto ierīces nosaukumu, iOS piešķirtu ierīces identifikatoru, signāla stiprumu un savienojuma informāciju. Līnijai piesaistītais attālums saglabājas projektā; Bluetooth ierīces identifikators projekta datos netiek saglabāts.

Kameras un Bluetooth atļaujas var pārvaldīt ierīces iestatījumos. Atteikums ierobežo attiecīgo funkciju. Varat izvēlēties foto un strādāt bez pieslēgta mērītāja. Sistēmas atļauja pati par sevi nenozīmē piekrišanu nosūtīt projektus izstrādātājam.

Glabāšana, dzēšana un eksports

Projektiem lietotnē nav automātiska glabāšanas termiņa. Foto un projektus varat dzēst lietotnē. Tas neizdzēš oriģinālus Photos bibliotēkā, kopīgotos failus vai ierīces rezerves kopijas. Bojātu ierakstu faili var saglabāties atkopšanai. Ja tīrīšana neizdodas vai lietotnes darbība tiek pārtraukta, var palikt atsevišķi vai pagaidu faili; tūlītēja visu kopiju dzēšana netiek garantēta.

“Eksportēt foto” sagatavo JPEG ar mērījumu līnijām un attālumiem. Jūs iOS kopīgošanas izvēlnē izvēlaties saglabāšanas vietu vai saņēmēju. Saņēmēja lietotne vai pakalpojums piemēro savus noteikumus. Eksports nav anonimizācija vai pilna projekta rezerves kopija.

iOS, iCloud un izvēlētie kopīgošanas pakalpojumi var pārsūtīt datus, piemēram, foto saņemšanai no iCloud vai ierīces dublēšanai. Tas atkarīgs no jūsu iestatījumiem un pakalpojumiem. MetriPin rezerves kopiju izveide un atjaunošana nav verificēta un netiek garantēta.

Atbalsta vēstules un jūsu nosūtītie pielikumi

Rakstot izstrādātājam, jūs nododat savu e-pasta adresi, ziņā norādīto vārdu un citu informāciju, vēstules saturu un pievienotos failus. Tos izmanto atbildei uz konkrēto pieprasījumu un tajā aprakstītās problēmas izmeklēšanai. Sūtiet tikai nepieciešamo; parasti sākumā pietiek ar problēmas aprakstu. Nesūtiet nevajadzīgus citu personu datus vai sensitīvu informāciju.

Šīs apstrādes pamats ir VDAR 6. panta 1. punkta f) apakšpunkts: izstrādātāja leģitīmā interese sniegt jūsu pieprasīto tehnisko atbalstu un novērst konkrētas lietotnes kļūmes. Apstrāde aprobežojas ar pieprasījumam nepieciešamo informāciju, nevis reklāmu vai lietotāju profilēšanu. Varat iebilst pret šo apstrādi.

Datu nosūtīšana atbalstam ir brīvprātīga un nav priekšnosacījums darbam ar projektiem telefonā. Bez atbildes adreses vai nepieciešamām tehniskām detaļām konkrēto pieprasījumu var nebūt iespējams atrisināt.

Atbalsta vēstules un lietotāja nosūtītos pielikumus izstrādātājs dzēš 90 dienu laikā pēc pieprasījuma noslēgšanas. Termiņš attiecas uz izstrādātāja rīcībā esošajām kopijām, tostarp atsevišķi saglabātiem pielikumiem. Tas nav lietotāja projektu glabāšanas termiņš un nenozīmē automatizētu dzēšanu.

Saziņai izmanto Gmail. E-pasta piegādē un glabāšanā piedalās Google un jūsu izvēlētais e-pasta pakalpojums. Google savu pakalpojumu datu apstrādi apraksta Google privātuma politikā. Šis pakalpojums nav MetriPin projektu mākoņkrātuve.

Lietotnes un Apple diagnostika

MetriPin nav iebūvētu trešo pušu reklāmas, analītikas vai automātiskas kļūdu augšupielādes SDK. Parastajā Release versijā netiek veidots MetriPin Debug failu žurnāls. Sistēmas žurnālā var nonākt eksporta pagaidu faila tīrīšanas kļūdas kods.

Testēšanas Debug versijās ir tehnisks žurnāls ar notikumu laiku, tehniskiem identifikatoriem, darbību un kļūdu informāciju, bez foto satura un projektu nosaukumiem. Tas saglabājas starp palaišanām divos rotējošos failos līdz aptuveni 1 MB katrs. “Eksportēt diagnostiku” ļauj jums izvēlēties saņēmēju; žurnāls pats netiek augšupielādēts. Ja to nosūtāt izstrādātājam atbalstam, piemēro iepriekš aprakstīto atbalsta datu kārtību un termiņu.

Atsevišķi Apple atkarībā no jūsu analītikas un diagnostikas iestatījumiem var darīt izstrādātājam pieejamus lietotnes kļūmju datus un lietojuma statistiku. Tā nav MetriPin Debug žurnāla augšupielāde. Apple apstrādi un kopīgošanas izvēles apraksta App Analytics & Privacy.

Ja izstrādātājs saņem šādus Apple datus, tos izmanto lietotnes kļūmju un stabilitātes analīzei. Ciktāl tie ir personas dati, pamats ir VDAR 6. panta 1. punkta f) apakšpunkts: leģitīmā interese noteikt un novērst tehniskas kļūmes, izmantojot tikai analīzei nepieciešamo diagnostiku, nevis veidot lietotāju profilus. Varat iebilst pret izstrādātāja veikto apstrādi. Apple kopīgošanas iestatījumus pārvaldāt atsevišķi savā ierīcē.

Atsevišķi lejupielādētas Apple diagnostikas kopijas izstrādātājs dzēš 90 dienu laikā pēc analīzes pabeigšanas. Termiņš attiecas uz izstrādātāja rīcībā esošajām kopijām, nevis Apple sistēmās glabātiem datiem. Šeit netiek solīta automatizēta dzēšana.

Vietnes apmeklējums un GitHub Pages

Šī informatīvā vietne ir atsevišķa no lietotnes un tās projektiem. Lapu kodā nav analītikas, veidlapu, ārēju skriptu, savu sīkdatņu vai pārlūka datu glabātuves izmantošanas.

Vietni mitina GitHub Pages. Lapas piegādei pakalpojums saņem tehnisko pieprasījuma informāciju; GitHub norāda, ka apmeklētāja IP adrese tiek reģistrēta un glabāta drošības nolūkiem arī bez pierakstīšanās GitHub. Skatiet GitHub Pages datu apstrādes skaidrojumu.

Izstrādātāja izvēlētās vietnes tehniskās piegādes nolūks ir nodrošināt pieejamu informāciju par lietotni, atbalstu un privātumu. Pamats ir VDAR 6. panta 1. punkta f) apakšpunkts — leģitīmā interese šo informāciju nodrošināt, izmantojot nepieciešamo tīmekļa pieprasījumu apstrādi bez apmeklējumu profilēšanas.

GitHub savu pakalpojumu un drošības datu apstrādē darbojas kā atsevišķs pārzinis. Tā nolūki, pamati un glabāšanas kritēriji aprakstīti GitHub privātuma paziņojumā. Šajā politikā noteiktie 90 dienu termiņi neattiecas uz GitHub žurnāliem.

Pakalpojumu sniedzēji un starptautiska apstrāde

Izstrādātājs atbild par saņemto atbalsta un diagnostikas kopiju izmantošanu šeit norādītajiem nolūkiem. Google, GitHub un Apple saviem pakalpojumu nolūkiem veic arī patstāvīgu apstrādi. Šī politika tos visā to darbībā nenosauc par izstrādātāja uzdevumā strādājošiem apstrādātājiem.

Šo pakalpojumu darbībā dati var tikt apstrādāti ārpus Eiropas Ekonomikas zonas, tostarp ASV. Google un GitHub publicē informāciju par ES–ASV datu privātuma regulējuma (DPF) izmantošanu attiecīgajām pārsūtīšanām un līguma standartklauzulām citos piemērojamos gadījumos. Garantiju aprakstus un informāciju par to kopiju saņemšanu skatiet Google pārsūtīšanas noteikumos un GitHub pārsūtīšanas sadaļā. Apple savas pārsūtīšanas apraksta Apple privātuma politikā.

Izstrādātāja noteiktā kopiju dzēšana nenosaka šo pakalpojumu sniedzēju patstāvīgo žurnālu vai rezerves sistēmu glabāšanas termiņus.
